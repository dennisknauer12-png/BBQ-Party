# End of Summer Barbecue – GitHub Pages

## 1. Platzhalter ersetzen
Öffne `index.html` und ersetze überall:
- `USERNAME` durch deinen GitHub-Benutzernamen
- `REPOSITORY` durch den Namen des neuen Repositorys

Dadurch werden WhatsApp-Vorschau und die Weiterleitung nach der RSVP-Antwort korrekt.

## 2. Auf GitHub hochladen
1. Neues Repository erstellen, z. B. `end-of-summer-bbq`.
2. Alle Dateien aus diesem Ordner in die oberste Ebene des Repositorys hochladen.
3. Repository öffnen → **Settings** → **Pages**.
4. Unter **Build and deployment**: **Deploy from a branch** wählen.
5. Branch **main**, Ordner **/(root)** wählen und speichern.

Die Website ist anschließend typischerweise unter `https://USERNAME.github.io/REPOSITORY/` erreichbar.

## 3. RSVP einmalig aktivieren
Beim ersten echten Absenden verschickt FormSubmit eine Aktivierungs-E-Mail an `dennisknauer12@gmail.com`. Den Link darin einmal bestätigen. Danach werden Zu- und Absagen per E-Mail zugestellt.

## 4. WhatsApp
In WhatsApp nur die GitHub-Pages-URL senden, nicht die HTML-Datei. WhatsApp zeigt dann Titel, Beschreibung und `preview.png`; beim Tippen öffnet sich die aktive Einladung im Browser.

## Technischer Hinweis
WhatsApp führt Websites nicht direkt innerhalb einer Nachricht aus. Der Link öffnet die aktive GitHub-Pages-Seite in WhatsApps In-App-Browser oder Safari. Das ist das normale und technisch zuverlässige Verhalten.
